## 📌 Project Overview

This project focuses on analyzing global air quality and weather data to explore pollution levels, compare environmental conditions across cities and countries, and examine changes over time.

Using Microsoft Excel and Power BI, the project demonstrates data cleaning, exploratory analysis, interactive visualization, and dashboard development to make environmental data easier to understand.

## 🎯 Project Objectives

- Analyze air pollution levels across cities and countries.
- Explore monthly and time-based pollution trends.
- Examine air quality alongside weather measurements.
- Transform raw data into meaningful summaries and visualizations.
- Present findings through interactive dashboards.

## 🗂️ Dataset Description

The dataset contains approximately **10,000 records** covering air quality and weather measurements.

| Category | Variables |
|---|---|
| Location | City, Country |
| Time | Date |
| Air Quality | PM2.5, PM10, NO2, SO2, CO, O3 |
| Weather | Temperature, Humidity, Wind Speed |

*Dataset details should be updated if your final source file differs.*

## 🔄 Project Workflow

1. **Data Inspection** — Reviewed columns, data types, missing values, and inconsistencies.
2. **Data Cleaning** — Standardized location names and validated dates and values.
3. **Data Transformation** — Prepared the dataset for analysis using Excel and Power Query.
4. **Exploratory Analysis** — Compared pollution measurements and examined time-based patterns.
5. **Dashboard Development** — Created visual summaries, charts, and interactive filters.
6. **Insight Communication** — Organized results into dashboards for easier interpretation.

## 📈 Key Analysis Areas

- City-wise and country-wise pollution comparisons.
- Monthly trends in air pollution measurements.
- Distribution of major pollutants such as PM2.5 and PM10.
- Exploration of air quality measurements alongside temperature, humidity, and wind speed.
- Interactive exploration of environmental data.

## 💡 Key Learnings

- Data cleaning and validation using Excel and Power Query.
- Summarizing datasets using PivotTables and PivotCharts.
- Creating interactive dashboards and visual reports.
- Exploring environmental data to identify patterns and trends.
- Communicating analytical results through visualizations.
