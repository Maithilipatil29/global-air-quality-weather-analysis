
# Global Air Quality & Weather Analysis Dashboard

## Project Overview
This project analyzes air quality and weather data to explore pollution patterns across cities and countries and understand changes over time.

## Tools & Technologies
- Microsoft Excel
- Excel Formulas
- PivotTables and PivotCharts
- Power Query
- Power BI
- DAX (where implemented)

## Dataset
The dataset contains approximately 10,000 records with air pollution and weather measurements, including PM2.5, PM10, NO2, SO2, CO, O3, temperature, humidity, and wind speed.

## Data Preparation
- Cleaned and standardized city and country names.
- Validated dates, data types, and inconsistencies.
- Transformed data for analysis.

## Analysis
- Compared pollution levels across cities and countries.
- Explored monthly pollution trends.
- Examined air quality alongside weather variables.
- Created interactive dashboard views and filters.

## Project Files
- `Excel_Dashboard.xlsx` — Excel analysis and dashboard.
- `PowerBI_Dashboard.pbix` — Power BI report.
- `Screenshots/` — Dashboard previews.

## Key Learnings
Practiced data cleaning, exploratory analysis, data visualization, dashboard development, and communicating data-driven insights.
